# Selling AI Agents to Clients
*Pitch, pricing model, aur objections handle karna — bina cheap dikhe*

---

## Why Selling Skill Bhi Zaroori Hai

Best AI agent banana kaafi nahi hai — agar tum usko sahi tareeke se **sell** nahi kar sakte, to koi bhi client tumhe hire nahi karega, chahe tumhara code kitna bhi acha ho. Yeh guide "Getting Paid" guide ka agla step hai: **ab tumhe pata hai kya charge karna hai — yeh guide sikhati hai kaise pitch karna hai.**

---

## PART 1 — PRICING MODELS (Konsa Kab Use Karo)

```
Model                  │ Kaise Kaam Karta Hai              │ Best For
────────────────────────┼────────────────────────────────────┼──────────────
Fixed project fee       │ Ek baar $X, poora agent deliver    │ MVP, one-off builds
Setup fee + monthly     │ $X setup + $Y/month maintenance    │ Ongoing service
Usage-based             │ Base fee + per-conversation/action │ High-volume agents
Retainer                │ Fixed monthly, unlimited support   │ Long-term clients
```

**Real example:** "$150/month base + $0.50 per conversation handled by the AI" — yeh model client ke outcome se align hota hai. Client jitna zyada use karega, utna tum earn karoge — dono ka incentive match hota hai.

### Do Numbers Jo Matter Karte Hain

1. **Tumhara floor** — platform/API cost per client + tumhara time cost. Isse kam kabhi price mat karo.
2. **Client ka anchor** — problem unko currently kitna cost kar raha hai (manual labor, lost leads, slow response time).

**Price hamesha in dono ke beech mein set karo — apne floor ke zyada kareeb nahi, client ke anchor ke zyada kareeb.**

## PART 2 — THE PITCH (Structure)

```
1. Demo pehle, baatein baad mein
   → "Yeh dekho maine tumhare actual data pe kya banaya" beats
     koi bhi slide deck

2. Unki language mein baat karo, apni tools ki nahi
   → Client ko "RAG pipeline" nahi chahiye, unko
     "customer questions ka instant answer" chahiye

3. Ek narrow demo banao unke real content pe
   → Meeting se pehle unki actual FAQ/documents se
     ek chhota working demo bana lo

4. Number wahi do jo woh bina meeting ke approve kar sake
   → Simple, clear pricing — confusing tiers nahi
```

## PART 3 — COMMON OBJECTIONS (Aur Kaise Handle Karo)

```
Objection: "Yeh mehnga hai"
→ Reframe: "Yeh cost nahi, investment hai — kitna time/paisa
  yeh currently manually handle karne mein lagta hai?"

Objection: "Hum khud bana lenge"
→ "Bilkul bana sakte ho — lekin main isse 2 hafte mein
  deliver kar dunga jo tumhari team 2 mahine mein banayegi"

Objection: "AI galat jawab de sakta hai"
→ Guardrails aur human-handoff dikhao — batao ke kab agent
  escalate karta hai insaan ko

Objection: "Setup fee kyun?"
→ Setup fee discount kar sakte ho agar monthly retainer
  lamba commitment ho — but poora free mat karo
```

---

## PART 4 — AFTER THE FIRST 10 SALES

Pehle clients ko woh rate pe price kiya gaya tha jab tumne kabhi delivery nahi ki thi. Ab tumhare paas proof hai:

```
✓ Case studies banao (before/after metrics ke saath)
✓ Rates badhao — purane clients grandfather kar sakte ho
✓ Subscription/retainer model ki taraf move karo
   (one-off build ka margin sirf ek baar milta hai,
   monthly retainer compound hota hai)
```

---

## PART 5 — MVP Pricing Reference

```
Typical MVP (2-3 months, fixed budget agreed in advance):
  ~$10,000 for a working custom AI agent

Yeh benchmark hai jahan se negotiate karna start kar sakte ho —
simple automation kam, complex multi-agent system zyada.
```
