### Rule 7: Workforce Ka Nervous System

**4 cheezein karta hai:**

**1. External Triggers (Jaagna)**
```
System khud uth ke kaam shuru kare:
Scheduled time + Webhook + Customer form + Doosra worker done
Bina triggers = Sirf tab jab insaan manually bole = chatbot!
```

**2. Internal Handoffs (Kaam Pass Karna)**
```
Workers ek doosre ko kaam dein bina insaan ke:
Support worker → Legal review chahiye
→ Automatically legal worker ko bhej deta hai
Bina handoffs = Insaan manually route kare = bottleneck!
```

**3. Durability (EXAM MEIN ZAROOR AAYEGA!)**
```
MATH:
Bina durability:
6 steps × 95% per step = 0.95⁶ = 74% success
= 4 mein se 1 kaam silently fail!

Durability ke saath:
Successful step save hota hai
Crash pe sirf failed step retry
= ~99.7% success!
```

**4. Flow Control (Traffic)**
```
Bina: 1 customer 1000 requests → sab power wahan
      → Baaki customers wait → System jam!

Ke saath: Har queue ko fair share
          Ek burst doosron ko affect nahi karta
```

**Bina nervous system ke kya hoga:**
```
Bina triggers  → Manual prompting = chatbot
Bina handoffs  → Human routing = bottleneck
Bina durability → 74% success = unreliable
Bina flow control → 1 customer blocks sab
```

**2026 Reference Implementations:**
Inngest (main) + Claude Code Routines (coding agents)

**Real validation:** Day AI company ke founding engineer Erik Munson ne apni Inngest layer ko "nervous system" kaha — yeh real builder ka real experience hai!
